Wer hat das geliked?

Jede Person lädt ihren Instagram-Datenexport hoch. Das Spiel zeigt dann einen Beitrag – und ihr ratet, aus wessen Likes er stammt.

  1. Export anfordern Instagram-App → Einstellungen → Konten-Center → Deine Informationen und Berechtigungen → Informationen exportieren. Format JSON.
  2. ZIP hier ablegen Die Datei bleibt auf diesem Rechner. Gelesen wird nur likes/liked_posts.json.
  3. Raten Ab zwei Spielern geht es los. Mit einem Spieler gibt es die Galerie.

    Was mit deinen Daten passiert

    • Nur eine Datei wird gelesen. Aus dem Archiv wird ausschließlich likes/liked_posts.json entpackt. Nachrichten, Fotos, Videos und alle übrigen Ordner werden nicht angefasst – sie werden nicht einmal entpackt.
    • Nichts wird hochgeladen. Das ZIP verlässt diesen Rechner nicht. Ausgewertet wird es im Browser.
    • Nichts wird gespeichert. Ein Neuladen der Seite löscht alle importierten Likes. Zwischengespeichert wird nur, ob ein Beitrag öffentlich abrufbar ist – das ist keine persönliche Information.
    • Beim Spielen lädt der Instagram-Embed. In der Spielrunde wird der offizielle Einbettungs-Code von Instagram geladen; Instagram sieht dabei den Beitrag, nicht aber, wer ihn geliked hat. Die Galerie kommt ohne aus.

    Beiträge werden geprüft

    Jeder gelikte Beitrag wird einmal daraufhin angesehen, ob er öffentlich abrufbar ist. Private, gelöschte und gesperrte Beiträge fliegen raus, damit im Spiel keine kaputten Kacheln stehen.
